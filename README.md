# astrbot_plugin_conversation_manager · 对话管理

在 AstrBot Dashboard 左侧边栏提供「对话管理」页面：可视化浏览、编辑、删除、插入任意平台会话的消息，支持自动快照撤销、JSONL 导入导出、手动分块压缩摘要。

> ⚠️ **本插件会直接修改会话历史数据。** 每次保存前会自动创建快照（可一键回滚），但仍请保持快照功能开启，并在批量操作前先「导出」留档。

## ✨ 功能

- **会话列表**：全部对话一览（消息数、est token、最后预览、更新时间），自动刷新可开关
- **消息时间线**：气泡式渲染，模型 `think` 思考过程默认折叠展示（点击可展开），系统提醒不干扰阅读（时间已提取到消息头），大历史分页懒加载
- **编辑**：修改任意文本内容、**模型思考过程（`think` 的修改/新增/清空）**与角色（user/assistant）；图片/工具等非文本内容只读保护
- **删除**：单条删除 / 整轮删除 / 截断到某条为止 / 任意位置插入
- **自动快照**：每次保存、导入、压缩前自动快照，面板内一键回滚，保留份数可配置（默认 20）
- **JSONL 导入导出**：与 AstrBot 对话数据同构，一键备份/恢复/迁移
- **手动压缩**：把旧对话交给**你自己选的模型**生成摘要后替换头部（分块摘要+自动合并，小窗口本地模型也能处理超长历史），彻底摆脱云端内容审核对自动压缩的影响
- **上下文压力指示**：实时估算 est token 与阈值距离，提示"还剩几条会触发自动压缩"

## 📦 安装

- **插件市场**：AstrBot Dashboard → 插件 → 插件市场 → 搜索「对话管理」
- **手动**：
  ```bash
  git clone https://github.com/lychee522/astrbot_plugin_conversation_manager.git
  # 将目录复制/软链到 AstrBot 的 data/plugins/ 下，重启 AstrBot 即可
  ```

要求 AstrBot **>= 4.26**（依赖插件页面 pages 机制与 conversation_manager API）。无额外 Python 依赖。

## 🚀 使用

1. 登录 Dashboard，左侧边栏点击「对话管理」
2. 左侧选择会话 → 右侧浏览消息
3. 鼠标悬停消息出现操作按钮：✏ 编辑 / 🗑 删除 / ⏬ 删轮 / ➕ 插入 / ✂ 截断
4. 修改只存在于本地，点顶部「保存更改」一次性写回（写回前自动快照）
5. 「压缩」按钮：选择一个模型（建议内容敏感场景选择本地/无审核模型）→ 开始压缩，后台执行，完成后自动刷新

## ⚙️ 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| snapshot_keep | 20 | 每对话快照保留份数 |
| poll_interval | 5 | 面板自动刷新间隔（秒，0=关） |
| token_threshold | 12800 | 上下文压力估算阈值（est token） |
| compress_keep_ratio | 0.15 | 手动压缩默认保留最近比例 |
| compress_instruction | 空 | 摘要指令（留空用内置默认） |

以上均可在面板「⚙ 设置」中热修改。

## 🧭 设计说明

- 数据层只走 AstrBot 官方 `conversation_manager` API，不直接访问数据库，跨版本安全
- 页面通过 AstrBot 插件页面（pages）机制挂载在 Dashboard 内，鉴权继承 Dashboard 登录态，**无需额外端口与密码**
- 保存采用乐观锁：编辑期间若有新消息进来会提示合并，绝不盲写覆盖
- 任何面板错误都不影响 bot 主流程
